# 轻安 / Molt — 可玩原型（纵向切片）

一个等距视角的中式古建空间解谜游戏原型（纪念碑谷式玩法 + 道家骨架 + 禅意水墨）。
玩家旋转 / 操纵"不可能几何"，引导一个负重行者走到出口；沿老子"为道日损"逐关卸下执念。

> 详见 `HANDOFF_ClaudeCode_技术交接.md`（工程）与 `PRD_轻安_产品与决策文档.md`（产品）。

## 运行

```bash
npm install
npm run dev      # 本地开发 http://localhost:5173
npm run build    # 产出静态站点到 dist/（可直接部署 GitHub Pages / itch.io / Vercel）
npm run preview  # 预览生产构建
```

## 核心思路（一句话）

**关卡是数据，运行时是通用的。** 不造"通用的不可能几何求解器"——
每关的"不可能连接"由**手工授权的数据**描述：一条可行走的 edge 只有当机关处于某个
吸附态时才存在（因为只有那时几何在固定相机视角下才"接上"）。
这就是把"相机空间的邻接"编码成数据，绕开了最难的工程。

> 最容易翻车的不是渲染，是导航——"屏幕相邻 ≠ 空间相邻"。见 `src/engine/Navigation.js`。

## 关卡数据模型

关卡是纯 JSON，运行时读它即可跑（Sally 可直接编辑 + 用 debug 叠层调关）。字段：

- `geometry` — 静态几何（基础体拼）。
- `mechanisms` — 可切换吸附态的机关（`rotate` 旋转 / `extract` 抽棂条）。
- `nodes` — 角色能站的点。
- `edges` — 可行走连接；`requires` 为空恒有，否则需机关处于指定状态才激活。
  `seam:true` 标记接缝：两节点 3D 不连续、屏幕连续，角色瞬移过去。
- `start` / `exit` — 起点与出口。
- `script.dropOnNode` — 到达某节点时卸下第 N 件负重（剪影即进度条）。

## 操作

- **点击关卡** 进入；左上「← 山门」返回。
- **拖动 / 点击朱砂手柄** 切换机关吸附态 → 世界重组、可达高亮刷新。
- **点击亮起（朱砂环）的节点** → 角色寻路走过去。到达出口即通关。
- 右上 **debug** 开关：显示所有节点、当前激活 edge。
